# `Beal/Mazur/Frey/`

This folder contains the Frey-side entrance to the Level-26 Mazur route. It
connects a primitive Beal counterexample to the displayed Frey model and to
the level-lowering boundary that would produce a noncuspidal rational point
on `X₀(26)`.

In *Opera Numerorum* terms, this is the bridge from the elementary Beal room
to the arithmetic-geometry rooms below. The interface is proof-relevant and
typed, but it remains conditional: constructing all global conductor,
modularity, and level-lowering inputs is outside this folder.
