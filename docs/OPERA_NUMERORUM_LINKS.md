## The wider work

This repository, [beal-conjecture](https://github.com/DavidFox998/beal-conjecture), is the public home of the Beal formalization. Historical notes below this index sometimes describe other chambers. Those chambers are not public locations, and this page does not link to them.

The Beal work in this repository is not a proof of the general conjecture. `main` is the Matveev–Baker and level-26 foundations line. The current `(4,4,13)` prototype is the branch `mathlib/remove-ribet-axiom` of the same repository. That branch has two axioms and five open propositions. See its `README.md`.

Axiom footprint aimed at throughout: `{propext, Classical.choice, Quot.sound}`, with no `sorry`.

### Formalization reference
[ImperialCollegeLondon/FLT](https://github.com/ImperialCollegeLondon/FLT) is a public formalization of Fermat's Last Theorem. It is an inspiration, not a dependency of this repository.
