# v1.4.0 — FormalImmersionM3 ledger match

This release records the Lean 4.12 bridge
`Beal.Foundations.FormalImmersionM3`, which reads
`sagemath/certs/formal_immersion_M3.json` as typed data over `ZMod 3` and
checks it against `sagemath/level_26_ledger.json`.

It proves only:

- `M₃ = [[1, 1], [0, 2]]`;
- `det M₃ = 2`;
- equality with the ledger-derived matrix `ledgerM3`.

These are `decide` theorems. The module does **not** construct a Mathlib
Jacobian, prove a Mordell--Weil rank, or identify `M₃` with a geometric
Picard/Abel--Jacobi cotangent map. There are no `sorry`, `admit`, or domain
axioms.
