# v4.0.7-hIdentify-j — typed `hIdentify` by finite `j`

This release redefines the typed EndgameScaffold propositions so
that a displayed level-26 target is not confused with integer
non-membership in the four-cusp list.

* `ExistsFreyWitness` is a Frey Weierstrass model over `ℤ` with
  `Δ ≠ 0` and `loweredLevel = 26`.
* `ExistsNoncuspidalLevel26FreyPoint` is an elliptic `j`-ratio
  `(c₄³ : Δ)` packed as `DisplayedX026PointKind.ellipticJ`, a
  different constructor from the cusp-divisor labels
  `[1, 2, 13, 26]`.
* `HIdentifyActual_26.hIdentify` / `HIdentify26.of_qExpansion`
  inhabit `ExistsFreyWitness → ExistsNoncuspidal` from that
  packing together with certified `26a × 26b` (`a₂ = -1` versus
  `1` by `decide`), `MwrankCertificateSoundness_26`, and
  `X0_26_RationalPoints26.of_qExpansion`.
* `NoFreyPointActual_26` keeps the four-cusp *list*. It does not
  Lean-negate the elliptic-`j` witness.

v4.0.7-hIdentify correctly refused to inhabit the *old* typing
(`26 ∉ [1, 2, 13, 26]`), which made the implication
`True → False`. This tag changes the typing, not the geometry:
Mathlib 4.12 still has no `X₀(26)` point API. Four cusp labels
do not Lean-negate an elliptic `j` as a modular-curve point.
`hGeomForbid` remains the named remaining geometric gate.
There is no unconditional `theorem BealTheorem`.
