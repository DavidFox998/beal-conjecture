# v4.0.9-fourCusps-forall — cusp-point forall, typed `hGeomForbid` still uninhabitable

This release retypes the four-cusp package as a forall over
displayed *cusp-labeled* points:

`∀ (P : DisplayedX026CuspPoint), ∃ n ∈ [1, 2, 13, 26], P.kind = cuspDivisor n`

That proposition is `fourCuspsForallCuspPoints`. The list is the
witness. The domain excludes `ellipticJ`, so the forall does not
Lean-negate `ExistsNoncuspidalLevel26FreyPoint`.

A same-type forall over all `DisplayedX026PointKind` would be the
statement the geometric gate needs. That proposition is
`fourCuspsForallAllKinds`, and it is false: `ellipticJ` is a
counterexample (`fourCuspsForallAllKinds_is_false`).

The typed EndgameScaffold hypothesis

`fourCusps → ¬ ExistsNoncuspidalLevel26FreyPoint`

therefore remains `True → ¬True`.
`HGeomForbidActual_26.hGeomForbid_typed_is_uninhabitable` still
records that fact. This release does not inhabit typed
`hGeomForbid` and does not add `theorem BealTheorem`.

Mathlib 4.12 has no `X₀(26)(ℚ)` API. The remaining geometric
gate is a Frey curve as a noncuspidal rational point of that
modular curve.
