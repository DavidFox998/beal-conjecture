# `docs/Level26/`

Ledger data for the historical Level 26 finite audit in the
beal-conjecture assembly (v11 / v8.9 Real 80-Check).

[`level_26_ledger.json`](level_26_ledger.json) stores the
displayed 26a1 / 26b1 quartic rows used by
`lean/Beal/Mazur/Gates/SecondDescent_Real_26.lean`. Passing
those eighty pairs at `p=2` and `p=13` is a finite check, not
a proof that the 2-Selmer group is `{1}`.

The v26 honest Selmer cardinality `|Sel₂|=1` for Cremona 26a1
and 26b1 lives on the slice
[`../../Level26/HonestB0Search/TwoDescent_26a1_26.lean`](../../Level26/HonestB0Search/TwoDescent_26a1_26.lean)
(`7c19ad0`), not in this JSON.
