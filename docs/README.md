# `docs/`

This folder is the written map for the Beal chamber in *Opera Numerorum*. It
keeps the mathematical narrative beside the Lean source without asking a
README or a theorem name to carry more certainty than the code supports.

The Level-26 documents explain the explicit genus-two model and the rational
point boundary. `release/` preserves release-specific notes and historical
milestones. Together they trace the route from finite arithmetic evidence to
the conditional Frey/Mazur endgame.

[`OperaNumerorum_v10.md`](OperaNumerorum_v10.md) is the narrative map for the
v10.0.0 final assembly. It follows a hypothetical primitive Beal
counterexample through the Frey, modularity, level-lowering, rank-zero, and
formal-immersion interfaces to the four-cusp contradiction.

The standing rule is simple: executable evidence, external computation, and
unproved mathematical interfaces are described separately. A green build
confirms the stated formal boundary; it does not silently close Wiles, Tate,
Jacobian, Selmer, or rational-point obligations.
