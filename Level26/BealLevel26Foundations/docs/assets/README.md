# Historical documentation assets

This folder holds the illustrated assets used by the nested Level26
documentation. `v6.7.0/` groups version-specific diagrams in several
image formats; use these alongside the corresponding markdown in
`../`. These are documentation resources, not Lean proof inputs.

The current root-tree v33 work is in `Beal/Beal.General/`, not this
historical subtree: `SpecialFibreGluing.lean` (167 lines) glues the
three polynomial chart spectra; `CompatChart2t.lean` (191 lines),
`CompatChartXt.lean` and `CompatChartYt.lean` (105 each) identify the
charts, and `CompatPolynomialRestrictions.lean` checks six directed
restrictions. Product overlaps remain abstract pullbacks.
