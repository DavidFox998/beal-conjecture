# v4.0.2-selmer — S-unit audit versus genuine 2-Selmer

This release audits the eight signed S-unit indices
`[1, -1, 2, -2, 13, -13, 26, -26]` that accompany
`sagemath/certs/j0_26_decomposition.json` against genuine
cohomological 2-Selmer.

`BealLevel26Foundations.Jacobian.TwoSelmer_vs_SUnits_26` proves that
the finite `8 × 10` audit retains all eight indices and is not a
singleton. Per the v1.0 README boundary, that audit is therefore not a
genuine 2-Selmer calculation: comparison with the genuine
cohomological 2-Selmer group remains future mathematics.

From that audit it certifies the finite package
`MwrankCertificateSoundness_26` for `26a` and `26b`: Sage
`certified_mwrank = 0` together with the already-decided finite model
`s₁ = q₁ + q₂`, `s₂ = -q₁ q₂` and the q-expansion distinction
`a₂ = -1` versus `1` from `J0_26_DecompActual`.

No new certificate is added. The v1.4.0 ledger SHA-256
`0259fe957cc348b7286e233ce717fac47c30ad174b05e8e1c5fb70626f511151`
is unchanged. This is not a Mathlib Jacobian, Galois-cohomology, or
Mordell--Weil theorem, and it does not discharge the parent geometric
`MwrankCertificateSoundness_26` premise.
