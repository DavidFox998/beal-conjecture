## Corrected signed-twist audit

This release supersedes v1.0.0-computable. The first archive correctly shipped
the signed-twist strong-Hensel replay, but its Lean finite-field theorem repeated
the ten untwisted row checks across eight indices without using the signed
S-unit in the equation. The corrected predicate now checks

\[
d y^2=q(x,z)
\]

for the actual signed representative \(d\), every one of the ten binary
quartics, and both bad primes \(2\) and \(13\). Lean proves all eighty resulting
finite-field local-solubility checks.

The standard-library replay remains a separate, stronger computational audit:
it checks 160 strong-Hensel witnesses, one at each signed twist, quartic row,
and bad prime.

## Exact boundary

This release does not identify the finite candidate carrier with the genuine
cohomological \(2\)-Selmer group, infer Mordell--Weil rank, or identify \(M_3\)
with the actual Abel--Jacobi cotangent map. Those remain named comparison
theorems for later releases.

There are no `sorry`, `admit`, vacuous `True` declarations, or domain-specific
axioms in the Lean source.
