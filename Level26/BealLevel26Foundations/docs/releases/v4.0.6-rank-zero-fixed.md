# v4.0.6-rank-zero-fixed — split existence from absence; product rank-zero package

This release fixes the v4.0.5 gate that made
`hGeomForbid : fourCusps → ExistsNoncuspidal → False`
uninhabitable. Displayed Ribet existence
(`ExistsFreyWitness`, `loweredLevel = 26`) is now a different
proposition from noncuspidal existence
(`ExistsNoncuspidalLevel26FreyPoint`, which also requires
`26 ∉ [1, 2, 13, 26]`).

## What landed

1. `Ribet/RibetLoweringActual_26.lean` keeps the former existence
   package: `ribetExistenceFromQExpansion` and
   `ofBealFreyLowering : ExistsFreyWitness` with witness
   `loweredLevel = 26`. Not a Mathlib Ribet theorem.

2. `Ribet/NoFreyPointActual_26.lean` now proves
   `NoFreyPoint26.not_exists` /
   `noNoncuspidalLevel26FreyPoint : ¬ ExistsNoncuspidal`
   from `X0_26_RationalPoints26.of_qExpansion` (divisors
   `[1, 2, 13, 26]`, length `4`). Not from existence.

3. `Jacobian/J0_26_Q_RankZeroActual_26.lean` inhabits
   `J0_26_Q_RankZero26.of_qExpansion` as the product of the two
   certified factors `26a × 26b` (`a₂ = -1` versus `1`) together
   with `MwrankCertificateSoundness_26` (Sage
   `certified_mwrank = 0` on both, plus `s₁,s₂` by `ring`).
   This does not use a Dedekind S-unit API and does not identify
   the eight-index audit with genuine `Sel₂`.
   `sUnitAudit26_is_not_genuine_2Selmer` remains in force.

4. `Mazur/EndgameScaffold.lean` defines `hGeomForbid` as
   `fourCusps → ¬ ExistsNoncuspidal`.
   `BealTheoremFromMazurChain26` uses the four packages to
   produce `ExistsFreyWitness` from a counterexample and
   `¬ ExistsNoncuspidal` from the four cusps. Identifying those
   two propositions is the named remaining gate `hIdentify`.
   There is no unconditional `theorem BealTheorem`.

No new certificate is added. The v1.4.0 ledger SHA-256
`0259fe957cc348b7286e233ce717fac47c30ad174b05e8e1c5fb70626f511151`
is unchanged.
