# v4.0.3-formal-immersion — q-expansion cotangent injectivity

This release inhabits the Mazur `FormalImmersionAtTwo26` premise from
already-checked q-expansion data.

`BealLevel26Foundations.Jacobian.FormalImmersionActual_26` proves that
`M₃ = [[1, 1], [0, 2]]` has `det = 2 ≠ 0` by `ring` and that
`v ↦ M₃ v` has trivial kernel by `decide`. Under
`PicardAbelJacobiIdentification_26`, any supplied matrix equal to the
q-expansion `M₃` is likewise injective.

`FormalImmersionAtTwo26.of_qExpansion` is that inhabitant. It can
replace the formal-immersion *input* premise in `EndgameScaffold`.
The scaffold is not collapsed: rank zero, `X₀(26)(ℚ) = four cusps`,
and no-Frey-point data remain supplied. This is not a scheme-theoretic
formal immersion of `X₀(26)` in `J₀(26)`.
