# v4.0.4-x026-rational-points — displayed four cusps from q-expansion data

This release inhabits the Mazur `X0_26_RationalPoints26` premise from
already-checked q-expansion and genus data.

`BealLevel26Foundations.Mazur.X026RationalPointsActual_26` takes the
displayed cusps `[1, 2, 13, 26]` (`= divisors26`,
`List.length = 4 = cuspCount26`) together with the certified
`26a × 26b` distinction `a₂ = -1` versus `1`, the finite package
`MwrankCertificateSoundness_26`, and
`FormalImmersionAtTwo26.of_qExpansion`.

`X0_26_RationalPoints26.of_qExpansion` is that inhabitant. It can
replace the `X0_26_RationalPoints26` premise in `EndgameScaffold`.
`ofRankZeroAndImmersion` returns the finite four-cusp package and
does not read a rank-zero witness. The scaffold is not collapsed:
`J0_26_Q_RankZero26` and `NoFreyPoint26` remain supplied. Mathlib
4.12 has no `X₀(N)(ℚ)` API. This is not a modular-curve
rational-point theorem.

No new certificate is added. The v1.4.0 ledger SHA-256
`0259fe957cc348b7286e233ce717fac47c30ad174b05e8e1c5fb70626f511151`
