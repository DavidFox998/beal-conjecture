# v3.0.0-ribet — typed LevelLowering_26 certificate

This release starts the PLAN.md v3.0.0 Ribet milestone. There is no v2.1.

`BealLevel26Foundations.Ribet.LevelLowering_26` defines `LevelLowering_26`
as indexed certificate data, not an opaque proposition:

* residual representation parameters `(ℓ, weight = 2)`;
* a level step `(N, p, M)`;
* the lowering relation `M * p = N` and `vₚ(N) = 1`.

It proves the arithmetic step onto level 26: from `p ∤ 26` conclude
`vₚ(26 p) = 1`, and the displayed factorization `26 = 2 * 13` with
`v₁₃(26) = 1` and `v₂(26) = 1`.

`RibetTheoremBoundary26` records that existence of a realizing modular
form at the lower level is an explicit boundary. It is not discharged
by `decide`.

This is not a Ribet theorem, not a modularity or `R = T` theorem, not a
Galois-representation construction, and not a replacement of the parent
`LevelLowering_26` supplier. The v1.4.0 ledger is unchanged.
