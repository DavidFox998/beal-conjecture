# Historical Tate algorithm

`RealTateAlgorithm.lean` is the nested Level26 project's Tate
algorithm material. Its imports and hypotheses belong to that
project; the root-tree `Beal/Beal.General/` is a separate local
geometry development.

Current root-tree v33 checks `CompatChart2t` (191 lines),
`CompatChartXt` and `CompatChartYt` (105 each), six
polynomial-to-abstract restrictions in
`CompatPolynomialRestrictions`, and three-open gluing in
`SpecialFibreGluing` (167 lines). Product overlaps are abstract.
