# Historical counterexample base

`BealCounterexampleBase.lean` sets up the base definitions used by
the nested Level26 Lean argument. See `../README.md` for the
surrounding module tree and the nested Lake project for dependencies.

Current root-tree v33 is separate: `Beal/Beal.General/` checks
`CompatChart2t` (191 lines), `CompatChartXt` and `CompatChartYt`
(105 each), six polynomial-to-abstract restrictions, and
`SpecialFibreGluing` (167 lines), with abstract product overlaps.
