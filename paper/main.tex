\begin{abstract}
The Beal equation $A^x+B^y=C^z$ with $x,y,z>2$ is studied here only
for the restricted one-parameter family $C=B+3$ inside the signature
$(4,4,13)$, i.e.\ $A^4+B^4=(B+3)^{13}$. This ``gap-3'' family is an
internal naming convention of a larger, still largely open Lean
development; it is \emph{not} derived in this repository from the
unrestricted equation $A^4+B^4=C^{13}$, and no claim about the
general signature is made. For the test parameters
$(A,B)=(29,1)$ in the displayed Frey model --- not a solution of
the gap-3 equation itself --- the associated Frey curve
$E:y^2=x(x-A^4)(x+B^4)$ has displayed conductor $928=2^5\cdot 29$,
N\'eron types $I_0^*$ at $2$ and $I_8$ at $29$, and valuations
$v_2(\Delta)=6$, $v_{29}(\Delta)=8$; Tate's algorithm itself is not
formalized in Mathlib~4.12, and the same family at $(A,B)=(1,1)$
displays conductor $32$, not $928$. This draft records the
Lean~4.12 verification of four families of displayed numeral and
Finset facts, named only by association with Tate, Mazur, Ribet,
and Kolyvagin; none of the four classical theorems is proved.
Mazur-named display: $\lvert\SL_2(\F_{13})\rvert=2184$, $48<2184$,
$13=2^2+3^2$, $288/48=6$, cusp Finset card~$2$; $X_0(13)$ has
genus~$0$, so $X_0(13)(\Q)$ is infinite and no $13$-isogeny is
excluded by this display. Ribet-named display: $928/29=32$, an
empty matching Finset (card~$0$) against the LMFDB dimension-$1$
newform space at level $32$ (\texttt{32a1}). Kolyvagin-named
display: $\lvert\Sel_2\rvert=1$, $3\cdot 7=21$, $L/\cO=1/3$ and
$1/7$ on Cremona \texttt{26a1}/\texttt{26b1}, and the typeclass
upgrade $\mathrm{Nonempty}(\mathrm{Fintype}\,\alpha)\to
\mathrm{Finite}\,\alpha$; the repository's surrogate
\texttt{IsSubsingleton := Subsingleton} (renamed from
\texttt{IsRankZero} in this revision) is not the conventional
algebraic-rank-zero predicate, and its application to each curve is
false, since both have nontrivial torsion. Separately, the
repository proves a genuine finite lemma,
\texttt{no\_match\_32a1\_of\_good\_red\_29}: on the gap-3 equation
with $29\nmid A$, $29\nmid B$, $29\nmid B+3$, the Frey trace at
$29$ cannot equal $-10$, the trace of \texttt{32a1}, by an
exhaustive residue check compiled with \texttt{native\_decide}
(axiom \texttt{Lean.ofReduceBool}). This lemma is not connected in
Lean to Ribet's level-lowering step, which stays an uninhabited
\texttt{def Prop}, and it does not address $29\mid ABC$. The four
named displays themselves use explicit types and \texttt{decide},
not \texttt{native\_decide}. This revision's version DOI,
\texttt{10.5281/zenodo.22885060}, was reserved through Zenodo's
deposit API before publication so that this sentence could cite it
correctly (Section~\ref{sec:comp} explains why three earlier v31
records could not); it supersedes
\texttt{10.5281/zenodo.22863527} for
\texttt{v30.0.0-level-26-structural-verification}, which still
archives the pre-rename declaration names discussed above. Concept
DOI \texttt{10.5281/zenodo.22041831} (this repository's own concept
series; the separate \texttt{beal-level-26-foundations} repository
has its own concept DOI, \texttt{10.5281/zenodo.22379293}, with final
forward-interface version \texttt{10.5281/zenodo.22912430} and post-final
v25 retrofit \texttt{10.5281/zenodo.22922473}). The retrofit orders the
Matveev bound, level-$26$ arithmetic, proved $B<1000$ slice, and explicit
$B\leq10^6$ boundary without using numerical equalities backwards.
The integrated tagged snapshot is archived as
\texttt{10.5281/zenodo.22923337}. Because GitHub-triggered Zenodo minting
occurs after the tagged commit exists, that immutable snapshot cannot cite
its own new DOI; this post-release manuscript revision supplies the exact
citation without moving the tag.
\end{abstract}
