\section{Lean formalization --- explicit types}\label{sec:formal}

Every theorem in the four finals carries an explicit type. Lean~$4.12$
rejects \texttt{theorem foo := bar}. The required opens are
\texttt{open Nat Finset Classical}. Typical types are
$\mathbb{N}$, $\mathrm{Prop}$, $\mathrm{Finset}\,\mathbb{N}$, and
\texttt{Fintype}. Proofs use \texttt{decide} (or \texttt{norm\_num}
on $\Q$), never \texttt{native\_decide}, so
\texttt{Lean.ofReduceBool} does not appear.

\paragraph{Axioms.}
For the four packaged \texttt{\_final} displays of
Sections~\ref{sec:tate}--\ref{sec:kolyvagin}, allowed axiom lists
are $[\mathtt{propext}]$,
$[\mathtt{propext},\mathtt{Quot.sound}]$, and
$[\mathtt{propext},\mathtt{Classical.choice},\mathtt{Quot.sound}]$.
There is no \texttt{sorryAx} and no new axiom, and
\texttt{Lean.ofReduceBool} does not occur, i.e.\ none of the four
uses \texttt{native\_decide}. Parent files keep the algebraic names
as \texttt{def Prop}. Display files contain no new \texttt{def Prop}.
This does \emph{not} extend to every theorem in every file those
four displays import: Section~\ref{sec:ribet} records one lemma,
\texttt{no\_match\_32a1\_of\_good\_red\_29} in
\texttt{Level32Table.lean}, whose axiom list is
$[\mathtt{propext},\mathtt{Classical.choice},\mathtt{Lean.ofReduceBool},
\mathtt{Quot.sound}]$ because its proof uses \texttt{native\_decide}
on a finite residue check. Both were verified on the pinned
toolchain with
\texttt{lake build +Level32Table} followed by the file's own
\texttt{\#print axioms} lines (cache warm, $\sim 1.3$s), and,
for the companion theorem
\texttt{no\_sol\_with\_good\_red\_29\_of\_trace\_match}, with a
one-line standalone \texttt{lake env lean} check
(\texttt{import Level32Table; \#print axioms
no\_sol\_with\_good\_red\_29\_of\_trace\_match}), which also
reports \texttt{Lean.ofReduceBool}.
